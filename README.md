# Project Fermat

Landing site for Project Fermat. Currently a "coming soon" page.

## Stack

Static HTML/CSS — no build step. Deployed on [Vercel](https://vercel.com) at [projectfermat.vercel.app](https://projectfermat.vercel.app).

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Pushing to the `main` branch auto-deploys via the Vercel GitHub integration.
